# Note on temperature_energy_msp.csv (T2)

Stop condition reached: the saved logits in score_export are float16. At T = 1 the energy AUROC recomputed from them differs from the saved float32 value by up to 8e-4 (limit 1e-4), and MSP recomputed from them by up to 0.34 (saturated confidences). Therefore every column named energy_T* and msp_T* in per_run_operating_points.csv and the file temperature_energy_msp.csv are NOT valid and must not be used. All T = 1 operating-point columns (energy, msp, maxlogit AUROC, FPR@95, TPR@FPR1%, AUPR, OSCR) use the float32 saved scores and reproduce per_run.csv to 1e-16 (AUROC). The temperature grid is recomputed from float32 logits inside scripts/p4_rev_t3_feature_scores.py (GPU run); the corrected values will be in T3/per_run_feature_scores.csv.
